# Маршруты Кубани

Интерактивная карта транспортной активности населённых пунктов Краснодарского края.

**Главная задача** — визуализация показателя **«Поездок на человека в год» (2025, Росстат)**:
каждый населённый пункт — точка на карте, цвет точки зависит от значения показателя
(холодные тёмно-синие — низкие значения → яркие оранжевые — высокие; серые — данных нет).

## Возможности

- Тёмная технологичная карта (MapLibre GL JS) с контуром края и границами районов;
- Цвет точек — по квантильной шкале основного показателя, размер — по населению;
- Hover: название, значение показателя, население;
- Клик / поиск / рейтинг → карточка НП со всеми показателями строки CSV;
- Рейтинг топ-10 / анти-топ-10 с переходом к точке;
- Легенда с порогами шкалы; переключение на доп. показатели
  (автобусы, автобусы на 10 тыс. жителей, пассажирооборот на человека);
- Адаптивная вёрстка (мобильные: нижняя выдвижная панель);
- Слой дорог OSM (векторные тайлы OpenFreeMap): подсветка и название/класс при наведении
  (это географический слой инфраструктуры, **не** автобусные маршруты).

## Данные

- **Статистика**: Росстат, 2025 (`data/rosstat_2025.csv`, 107 НП). Основной показатель
  заполнен у 30 НП; 72 НП отображаются серыми точками «нет данных»; 5 НП без координат
  в исходном CSV на карту не попадают (перечислены в логе `prepare_data.py`).
- **География**: границы муниципальных образований — © OpenStreetMap contributors
  (репозиторий [Russia_geojson_OSM](https://github.com/timurkanaz/Russia_geojson_OSM));
  дороги и подписи — векторные тайлы OpenFreeMap (OpenMapTiles, © OpenStreetMap contributors).
- Обработка пропусков: значения не выдумывались и не интерполировались;
  отсутствующие значения выводятся как «нет данных».

## Структура

```
index.html        — разметка интерфейса
style.css         — тёмная тема
script.js         — карта, интерактив, поиск, рейтинг, легенда
prepare_data.py   — CSV → GeoJSON + шкалы (pandas)
data/             — rosstat_2025.csv, points.geojson, region.geojson, scale.json
requirements.txt  — зависимости python
.github/workflows/deploy.yml — автопубликация на GitHub Pages
```

## Запуск локально

```bash
pip install -r requirements.txt
python3 prepare_data.py          # пересобрать данные (нужен доступ в интернет)
python3 -m http.server 8000      # откройте http://localhost:8000
```

(`prepare_data.py` можно не запускать — подготовленные файлы в `data/` уже в репозитории.)

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите файлы проекта (корень).
2. Settings → Pages → Source: **GitHub Actions** (используется `deploy.yml`), или
   Source: **Deploy from a branch** → `main` / `/root`.
3. Готовый сайт: `https://<username>.github.io/<repo>/`.

## Ограничения

- Дороги — справочный слой OSM (motorway…secondary); связь отдельных дорог
  с показателем поездков данными не подтверждена, цветом не кодируется.
- 5 НП без координат и 77 НП без значения показателя не участвуют в цветовой шкале.
- Для отображения карт требуются внешние CDN (unpkg) и тайлы OpenFreeMap.
